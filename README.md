One 1024×1024 image summing up Tuesday 17 November 2026's world news, set as a front page: the date in
the masthead, the overnight strike on the Kerch Bridge as the lead, and six region cards with a strip of
the day's numbers — US strikes on an Iranian missile site, Trump in Manila before the APEC trilateral,
Nvidia's beat after Jensen Huang's exit, COP31's disputed draft in Antalya, the Americas losing
measles-free status, and DR Congo's Ebola outbreak passing 11,000 cases — plus a ticker for Gaza aid,
United's outage and Ghana's first forest-carbon credits.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It copies `entry.png`, the entered image, to the output directory. `main.ts` uses the Node standard
library only and needs no network. `tools/front-page.html` is the page the image was rendered from.
